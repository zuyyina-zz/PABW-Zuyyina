# Pembuat Modul: Linear Regression vs Logistic Regression

## Tujuan
Menghasilkan modul pembelajaran lengkap, mendalam, dan terstruktur setara 10 halaman tentang perbandingan Linear Regression dan Logistic Regression untuk mata kuliah Machine Learning / Data Science.

## Struktur Isi Modul (10 Bab/Bagian)

Setiap modul wajib memuat bab-bab berikut dengan pembahasan yang kaya dan tidak terburu-buru:

1. **BAB 1: Pendahuluan & Konsep Dasar Supervised Learning**
   - Pengenalan Supervised Learning
   - Definisi Masalah Regresi vs Klasifikasi
2. **BAB 2: Fundamental Linear Regression**
   - Konsep dasar, fungsi garis regresi, persamaan matematika sederhana
   - Parameter Intercept dan Slope
3. **BAB 3: Asumsi dan Cara Kerja Linear Regression**
   - Asumsi Linearitas, Homoskedastisitas, Normalitas, No Multicollinearity
   - Konsep Loss Function: Mean Squared Error (MSE) & Ordinary Least Squares (OLS)
4. **BAB 4: Fundamental Logistic Regression**
   - Mengapa Linear Regression gagal untuk Klasifikasi Biner
   - Fungsi Sigmoid (Logit) dan pemetaan probabilitas (0 hingga 1)
5. **BAB 5: Fungsi Keputusan & Loss Function Logistic Regression**
   - Threshold decision (Decision Boundary)
   - Loss Function: Binary Cross-Entropy / Log Loss
6. **BAB 6: Tabel Perbandingan Komprehensif**
   - Perbandingan parameter, tipe variabel respon, output, fungsi aktivasi, dan alogaritma optimasi
7. **BAB 7: Evaluasi Model (Model Evaluation Metrics)**
   - Metrik Regresi: MAE, MSE, RMSE, R-Squared
   - Metrik Klasifikasi: Confusion Matrix, Accuracy, Precision, Recall, F1-Score, ROC-AUC
8. **BAB 8: Studi Kasus Nyata (Real-World Use Cases)**
   - Contoh penerapan Linear Regression (Prediksi Harga Rumah / Gaji)
   - Contoh penerapan Logistic Regression (Deteksi Spam / Diagnosis Penyakit)
9. **BAB 9: Kelebihan, Keterbatasan, dan Kapan Menggunakan Masing-masing**
   - Keunggulan dan kelemahan Linear Regression
   - Keunggulan dan kelemahan Logistic Regression
10. **BAB 10: Rangkuman & Soal Latihan/Evaluasi**
    - Rangkuman poin-poin inti
    - 5 Soal Teori & 2 Soal Studi Kasus beserta Pembahasan Singkat

## Aturan Penulisan
- Gunakan bahasa Indonesia akademis yang mudah dipahami.
- Sajikan penjelasan secara mendalam, sertai contoh analogi konkret.
- Hindari jawaban yang ringkas/singkat; berikan penjelasan yang panjang dan menyeluruh agar memenuhi standar bobot 10 halaman.
